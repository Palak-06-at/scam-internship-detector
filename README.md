# 🛡️ InternShield

### Apply Smarter. Spot Internship Scams Before They Spot You.

**InternShield is an internship scam detection platform designed to help students evaluate internship opportunities, identify suspicious recruitment practices, and make more informed application decisions.**

Finding an internship should be about building your career, not worrying about whether the opportunity is genuine.

InternShield analyses internship descriptions, identifies common scam indicators, and presents an understandable risk assessment so students can recognise potential red flags before applying.

---

## 🚨 The Problem

Students increasingly discover internships through social media, messaging groups, job portals, and unfamiliar recruitment websites.

Unfortunately, fraudulent internship listings can exploit students through:

- Upfront registration or application fees.
- Fake salary promises and unrealistic compensation.
- Guaranteed selection claims.
- Urgent application deadlines designed to create pressure.
- Requests for sensitive personal or financial information.

Many students struggle to distinguish suspicious opportunities from legitimate ones.

## 💡 The Solution

InternShield provides an accessible way to evaluate internship descriptions before taking the next step.

Instead of simply labelling a listing as real or fake, it highlights suspicious patterns, explains why they matter, and gives users practical safety recommendations.

## ✨ Key Features

| Feature | Description |
|---|---|
| Internship Analysis | Analyse pasted internship descriptions for suspicious patterns. |
| Risk Score | Generate a risk score based on detected indicators. |
| Red Flag Detection | Identify payment requests, unrealistic offers, urgency tactics and other warning signs. |
| Explainable Results | Show users which patterns triggered warnings and why. |
| Safety Recommendations | Provide actionable precautions based on the analysis. |
| Simple Interface | Make internship evaluation accessible without technical knowledge. |

## ⚙️ How It Works

1. **Paste:** Enter an internship description into the analysis interface.
2. **Analyse:** InternShield scans the text for predefined scam indicators.
3. **Evaluate:** The detection engine calculates a heuristic risk score based on identified patterns.
4. **Understand:** Review the detected warning signs and their explanations.
5. **Act Safely:** Use the recommendations to decide what additional verification is needed.

## 📊 Risk Assessment

InternShield categorises its results into three risk levels:

| Risk Score | Assessment |
|---|---|
| 0–29 | Low Risk |
| 30–59 | Medium Risk |
| 60–100 | High Risk |

The score represents the number and severity of suspicious indicators detected. It is a heuristic assessment, not a statistically validated probability of fraud.

**Important:** A low-risk result does not guarantee that an internship is genuine. Always independently verify the recruiter, organisation, website and offer.

## 🧠 Detection Approach

The current version uses a rule-based detection approach to identify suspicious language and recruitment patterns, including:

- Financial demands before employment.
- Unrealistic compensation promises.
- High-pressure recruitment language.
- Guaranteed placement or selection claims.
- Requests for sensitive information.

The focus is on explainable detection: users should understand *why* a listing was flagged, rather than receiving an unexplained score.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Palak-06-at/scam-internship-detector.git
```

Navigate into the project:

```bash
cd scam-internship-detector
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🎯 Product Vision

The long-term vision of InternShield is to become a student-first internship safety platform that helps people evaluate opportunities with greater confidence.

The goal is not just to detect suspicious listings, but to make safer internship applications easier and more accessible.

## ⚠️ Disclaimer

InternShield is an educational and informational tool. Its assessments are indicative and may produce false positives or false negatives. It does not independently verify employers, recruiters or internship offers and should not replace independent research.
